## SeekDB 读写结果

Dify 两个会话对应的 SeekDB 数据如下：

| SeekDB 表 | 实际结果 |
| - | - |
| `heartguide_turns` | 第一个会话 12 行（6 条 `user`、6 条 `assistant`），含五条验收输入和一条先前体验输入；第二个会话 4 行（2 条 `user`、2 条 `assistant`）。 |
| `heartguide_profiles` | 1 条；内容包含“雨天散步”和“先听我说”偏好。 |
| `heartguide_memory_reads` | 第一个会话 6 条（4 次 `preference_found=0`、2 次 `preference_found=1`）；第二个会话 2 条，均为 `preference_found=1`。 |

第二个会话的两次读取记录均命中已保存偏好；其 Dify 回复也明确复述了两项偏好。以下 SQL 可在同一 SeekDB 数据库复核，不需要公开用户标识：

```sql
USE test;

SELECT conversation_id, role, COUNT(*) AS rows
FROM heartguide_turns
WHERE conversation_id IN (
    '0722e22c-2ca4-4851-8d24-834e1ad4a7b1',
    '8a6a8f0a-abd2-468d-b181-ba5aecee006b'
)
GROUP BY conversation_id, role
ORDER BY conversation_id, role;

SELECT conversation_id, preference_found, COUNT(*) AS reads
FROM heartguide_memory_reads
WHERE conversation_id IN (
    '0722e22c-2ca4-4851-8d24-834e1ad4a7b1',
    '8a6a8f0a-abd2-468d-b181-ba5aecee006b'
)
GROUP BY conversation_id, preference_found
ORDER BY conversation_id, preference_found;

SELECT COUNT(*) AS profiles,
       MAX(preference LIKE '%雨天散步%') AS has_rain_walk,
       MAX(preference LIKE '%先听我说%') AS has_listening_preference
FROM heartguide_profiles
WHERE user_id = (
    SELECT user_id
    FROM heartguide_turns
    WHERE conversation_id = '0722e22c-2ca4-4851-8d24-834e1ad4a7b1'
    LIMIT 1
);

SELECT COUNT(DISTINCT user_id) AS shared_seekdb_users
FROM heartguide_turns
WHERE conversation_id IN (
    '0722e22c-2ca4-4851-8d24-834e1ad4a7b1',
    '8a6a8f0a-abd2-468d-b181-ba5aecee006b'
);
```

预期结果为：第一个会话每个角色各 6 行，第二个会话每个角色各 2 行；第二个会话有 2 条 `preference_found=1` 读取；偏好查询返回 1 条；`shared_seekdb_users` 为 1。
